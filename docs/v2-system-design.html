MCP Tool Design

boost_lesson(lesson_id)

Increments ups, increases boost by +0.3x (cap 3.0x). Updates Thompson Sampling with record_success. Rejects blocked/retired lessons. Warns if lesson not in curated.

Per-lesson Thompson

demote_lesson(lesson_id)

Increments downs, decreases boost by -0.4x (floor 0.0x). Auto-retires if boost hits 0.0 AND ups == 0 (never helpful). Warns if lesson has strong positive history (5+ ups).

Auto-retire Thompson

merge_lessons(ids, new_lesson, category)

Consolidates 2+ overlapping lessons. Applies all quality gates on new text. Combines ups, uses max boost. Marks sources as superseded. Physically removes sources from curated.

Consolidate Quality-Gated

create_lesson(lesson, category, ...)

V2 dual-path: writes to feedback_log.jsonl (for vectorization) AND curated_lessons.json (for injection). Auto-generates ID. Enforces 300 lesson cap.

Dual-Path Self-Healing

Claude's Decision Framework

When a feedback signal is detected, Claude receives a structured context with these rules:

RECENTLY INJECTED LESSONS:
ID     Category       Boost   Ups  Downs   Conf  Lesson
------ -------------- ------ ---- ----- ------  ----------------------------------------
L042   code_edit       1.3x    2     1    25%   Use semantic colors from theme tokens
L015   testing         2.0x    8     1    73%   Mock HTTP boundary, never internal code
L003   code_edit       0.7x    1     3    17%   Avoid hardcoded hex color values

DECISION FRAMEWORK — evaluate EACH lesson above:
  RULE 1: If lesson was harmful/irrelevant → call demote_lesson(lesson_id)
  RULE 2: If lesson was NOT relevant to what just happened → SKIP
  RULE 3: If two+ lessons overlap → call merge_lessons(ids, new, category)
  RULE 4: If feedback is about something NOT covered → call create_lesson(...)

CONSTRAINTS:
  - Max 5 tool calls total for this feedback round
  - Lessons with confidence <20% are unreliable — consider demoting or merging
  - Lessons with boost >=2.5x are already highly valued — only boost if clearly relevant

Lesson Lifecycle

Lesson State Machine
stateDiagram-v2 [*] --> Active: create_lesson / seed Active --> Active: boost_lesson (+0.3x) Active --> Active: demote_lesson (-0.4x) Active --> Retired: auto-retire (boost=0, ups=0) Active --> Superseded: merge_lessons Active --> Blocked: manual xN command Retired --> [*]: audit trail preserved Superseded --> [*]: audit trail preserved Blocked --> Active: unblock (u ID)

Auto-Retire

demote_lesson drops boost to 0.0 AND lesson has 0 ups (never helpful). Removed from curated, marked retired in scores.

Merge

merge_lessons combines 2+ overlapping lessons. Sources removed from curated, new consolidated lesson added. Reduces corpus size.

Corpus Cap

Soft cap at 300 lessons. _add_to_curated() returns actionable error at capacity. Dashboard shows percentage.

Edge Cases Handled

Edge CaseWhat Happens
curated_lessons.json missing_add_to_curated() creates it as []. Self-healing.
Corpus at 300 capacityReturns: "Corpus at capacity (300). Merge or demote lessons first."
No recent injectionRich context says: "NO LESSONS WERE RECENTLY INJECTED — create a new lesson instead."
Stale injection (>5 min)_reconstruct_injected_lessons() returns []. Claude defaults to create.
Demote lesson with ups=0 to 0.0Auto-retired. Removed from curated. Marked in scores with timestamp + reason.
Demote lesson with ups>0 to 0.0NOT auto-retired. Was helpful sometimes. Stays in curated at floor.
feedback_log.jsonl >10K linesMaintenance rotates: archive oldest, keep 5K recent, then remaps total_vectorized into the truncated file (legacy last_processed_line mirrored for compatibility).
Boost blocked/retired lessonRejected with clear error message. Must unblock first.
Boost/Demote unknown lesson IDRejected: lesson must exist in curated_lessons.json (prevents orphan score records).
Merge with missing source IDsError listing which IDs are missing. No partial merge.
Merge with duplicate IDsRejected with "unique lesson IDs" validation error.
