Features

Everything you need for AI memory

A complete system that captures, stores, ranks, and retrieves project-specific knowledge.

BGE-M3 + LanceDB hybrid search with cross-encoder reranking

Lessons That Prove Themselves

Install

One command. Any platform.

Choose your preferred method and you're up and running in under a minute.

$ brew install smartassist-memory/tap/smartassist
Then run:
$ cd my-project && smartassist setup

Recommended for macOS. Auto-updates with brew upgrade smartassist.

$ curl -fsSL https://smartassist-memory.com/install | sh
Then run:
$ cd my-project && smartassist setup

Works on macOS and Linux. Detects OS and architecture automatically.

$ npm install -g smartassist-memory
Then run:
$ cd my-project && smartassist setup

Thin wrapper that downloads the native binary on install.

$ pipx install smartassist
Then run:
$ cd my-project && smartassist setup

Python-native install. Requires Python 3.10+.

Works on macOS, Linux, and CI environments · Python 3.10+
